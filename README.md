# ThreadAnthem

ThreadAnthem enables intelligent distributed processing, auto-scaling, and real-time data management through a sophisticated controller.

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/ThreadAnthem.git`
2. `cd ThreadAnthem`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
